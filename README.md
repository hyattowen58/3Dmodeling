# 3Dmodeling
Using photogrammy software and Blender to model and animate 3D model.

## 3D Project Report
Documents project process, steps that led to proejct development, challanges that arose, and resources used to reach final porject video from the intrial scans of the ceramic mug.

## model.obj
The original model of the ceramic mug that was scanned from the images shown in the project report. Mug is untextured and was scanned using Scaniverse app.

## ceramic texture folder
The resources used to create the texture of the mug in the final video. Citation for this and other used models in the video are in the project report.

## 322 Final Video
The animated final video of the project. Shows the model through different lighting settings, various transformations (resizing, moving, reorienting, etc.), and interaction with other 3D models in a created environment including a table and a tiled floor. A detailed documentation of the process of creating the scene and animating it is within the project report.
